# Nota — WisprFlow en consulta

> 2026-08-29 — Para quien use esta MacBook (tiene Wispr Flow instalado).

**Ficha → Guía de consulta — este consultante**

- Cada fase (1-5) ahora tiene botón **🎙️** al lado del cuadro de texto.
- Flujo: tocar el cuadro de la fase → pulsar el hotkey de Wispr Flow → dictar → el texto cae directo en esa fase y el embudo (preguntas + biblio + cerebro) se recalcula en tiempo real con lo dictado.
- También sirve en **Sueños** (relato + diálogo) y en **Sesiones → Notas / QA** — cualquier `textarea` acepta dictado.

**Nota operativa**

- Orden de sugerencias: **1º notas de clase (capa B, escuela que seguís) → 2º bibliografía verificada (capa A)**. La biblio queda como respaldo, no como primera línea.
- Si la consulta es fuera de esta Mac (sin Wispr), el flujo es idéntico pero tipeando.
- Pendiente: probar atajo Wispr en consultorio y ajustar sensibilidad si corta frases largas.
